# Windows 实机 100 次演练 · v0.8.4

## 结论

在 Windows `win32`、完整紧凑结构化山东资料库上执行 100 个真实使用场景，结果为 **100 通过 / 0 失败**。本报告验证产品流程、专业边界、召回、关键口语和桌面交互，不等同于任一具体工程的计价准确率证明。

- 资料库：61,807 条定额、53,441 条清单、748,156 条人材机。

- 全部演练：约 93 秒；单次本地分析门槛为 12 秒。
- 原始逐项结果：`evaluation/reports/real-machine-100-v0.8.4.json`。

## 本轮发现并修复

1. 脚手架候选被误当增补：允许独立脚手架作为主项，并追问类型与高度。
2. JDG20 口语漏检：归一化 `JDG20`、墙内暗配和管径分档，命中 `4-12-8`。
3. 土球 80cm 分档错误：按土球尺寸排序，命中 `1-2-32`。
4. 材料未定仍给确定防水：状态改为 `needs_clarification`，追问 `material`。
5. 基础素混凝土误选钢筋：补充“基础垫层”和厚度语义，命中 `010501001-000 / 2-1-28`。
6. 道路“水稳”误选混凝土：归一化为水泥稳定碎石，命中 `040202014-000 / 2-1-18`。
7. 安装对象被追问土建人工/机械：过滤无关全局提示，避免小白收到无关问题。
8. 空方案污染导出探针：只把有清单或定额行的方案作为复制基准。
