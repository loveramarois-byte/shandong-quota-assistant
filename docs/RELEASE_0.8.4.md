# 0.8.4 发布说明

## 这次改了什么

- 首屏改为单一任务路径：`要套哪个项目？` → 示例填入 → `分析`。
- 默认示例从输入区移到欢迎状态，用户开始输入后自动消失。
- 结果默认只展示“推荐方案”；候选、原书、识别条件与导出收进“依据与候选”。
- “复制”用于审阅当前推荐；CSV/JSON 仍要求人工确认，避免把候选误当正式成果。
- 顶部统一显示 AI 连接状态，离线时仍保留本地资料能力，不再在首屏重复警告。
- 资料库状态收敛为“本地资料库 · 已就绪”，减少侧栏数字噪音。
- 全局 token 改为暖灰、低饱和橄榄色、Inter 字体和 4/8px 间距体系。
- Windows“显示动画”关闭时自动停用悬停渐变、平滑滚动和 Lottie 脉冲。
- 修复 JDG/KBG 口语、道路水稳、土球尺寸、基础素混凝土、脚手架主项等真实检索边界。

## 验收

- 237 项单元、资料库与发布门禁测试通过。
- Windows 完整结构化资料库 100 次实机演练：100/100 通过，0 失败。
- 100 次场景覆盖建筑、安装、市政、园林、小白口语、AI 设置、专业隔离、滚轮、DPI、导出和主题。
- 详细结果见 `evaluation/reports/real-machine-100-v0.8.4.json` 与 `evaluation/REAL_MACHINE_100_RUNS_V0.8.4.md`。

## 数据与安装

安装包包含已登记可分发的结构化资料库；紧凑安装包不重新分发 PDF 原书。普通套项直接使用结构化数据库，涉及换算、系数或争议时，依据区会提示用户结合自己持有的现行原书与项目资料复核。
