# 0.9.0 发布说明

## 两轮系统性重构

- 重建结果信息架构：AI 完成后只呈现一个最终结论面，不再同时堆叠本地候选卡和 AI 卡。
- 结论顺序调整为“结论、建议套用、匹配依据、专业明细”，并直接显示清单与定额编号、名称和单位。
- 统一浅色与深色灰绿中性设计 token，收敛圆角、边框、字号、内容宽度和控件高度。
- 精简页头和输入区重复说明，统一侧栏、筛选器、历史记录与资料状态的视觉层级。

## 一轮精修

- 鼠标滚轮动画缩短至 105ms，触控板滚动保持即时响应。
- AI 复核结果替换时保留人工阅读位置，大型结果面不再执行整卡透明度动画。
- 加载指示器提高刷新频率，并继续兼容减少动态效果与离屏测试环境。
- 新增安静的历史空状态、语义化 AI 连接状态，以及 Ctrl+K 聚焦输入、Ctrl+N 新建分析。
- 修复异常历史会话在关闭窗口时可能触发进程终止的问题。

## 验证范围

- 浅色与深色主题。
- 1080×680 最小窗口与 1280×820 常用窗口。
- 清单/定额编号显示、长文本换行、AI 复核滚动、历史恢复和键盘焦点。
