# 0.7.5 本地整改记录

整改依据：`山东定额助手_v0.7.3_实机演示20次不足报告.md` 及 20 条同源管线复现数据。

## P0 结果

- 给水管道安装不会再把“管道安拆后的充气保护”作为可确认方案。
- 橡塑保温不会再把“管道液压试验”作为可确认主定额。
- 外墙涂料不会再把“现浇混凝土地下室外墙”作为可确认主定额。
- 确认、复制、CSV 和 JSON 导出均要求合法清单、唯一主定额、`ready_for_review`、无硬冲突、无未决问题且证据页已定位。
- 整单状态取最差事项，并显示事项级完成度。
- 配管、苗木、管径和层数采用可操作的结构化澄清选项。

## 本地回归口径

- 自动化测试覆盖语义熔断、整单状态、确认门禁、AI 回填门禁和导出证据字段。
- 20 条实机描述继续作为发布前回归集；空输入必须可见拒绝，其余查询不得崩溃。
- 典型单事项热查询目标保持在 1.5 秒内；复杂多事项耗时单独记录，不用单事项指标掩盖。

## 仍需继续验证

- 外墙抹灰、给排水管材和复杂安装关联仍受原始清单—定额关系质量影响，遇到关系不足时保持不可确认。
- 300 条以上专家黄金集、Windows 代码签名和 5 名用户真实任务验证仍是进入 1.0 的前置条件。
