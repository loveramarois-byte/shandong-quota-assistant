# 山东定额助手成熟度审计

审计日期：2026-07-30  
对应版本：0.8.0

## 0.8.0 已解决

1. 重建中性灰与深绿色设计 token，统一原生标题栏、侧栏、输入区、结果区及浅深主题层级。
2. AI 对话收敛为绝对主入口；结果按“结论、事项方案、待补条件、核对依据”渐进展开，删除重复标题和内部引用噪声。
3. 鼠标滚轮与程序化定位使用同一可取消平滑滚动通道，修复滚动不同步与结果出现时跳动。
4. 修复 150% DPI 下内容宽度被二次缩放的问题，980×680 紧凑窗口不再截断长文本和状态操作。
5. 完整资料安装包改为单个自包含 EXE，自动创建桌面和开始菜单入口。

## 0.7.5 已解决

1. 新增对象、动作、材料、介质用途和施工部位的语义硬冲突熔断；给水误套充气保护、橡塑保温误套液压试验、外墙涂料误套混凝土墙均不得确认或导出。
2. 本地管线、AI 回填、结果卡、确认按钮、复制和导出共用同一个 `proposal_confirmable` 门禁，杜绝“清单未匹配但仍可确认”。
3. 整单状态按最差事项计算，并显示“已可确认事项 / 全部事项”；部分成功不再把整条描述标成可复核。
4. 澄清选项改为真实候选分面；配管直接提供钢管、塑料管、钢导管等选项，园林缺少土球/胸径时强制澄清。
5. 有清单但未形成主定额时保留最多三条“待人工选择候选”，但始终保持不可确认。
6. 确认导出新增假设/换算与证据页字段；缺少清单、唯一主定额、结构化状态或已定位证据时拒绝导出。
7. 查询词缓存并收敛两字词补召回范围，典型土方热查询已降至亚秒级；复杂多事项仍继续优化。

0.8.0 仍是 Beta / 内部试用版本。合成 demo 只证明技术链路可复现，不代表真实套价准确率。

## 结论

当前成熟度约为 **7.0/10**，定位是可供造价人员内部试用和持续校正的产品，不是已经证明高准确率的自动套价系统。

软件已跨过“资料搜索工具”阶段：它能拆分施工事项、限制专业和版本、按本地关联组装一条清单与多条定额、追问关键条件、定位原书证据，并让 AI 在本地白名单内解释。距离成熟“小而美”产品的主要差距已经不是界面，而是可量化的专业正确率、复杂做法覆盖和真实用户验证。

## 0.7.3 已解决

1. “C15 混凝土垫层，厚度 100mm”现在固定追问垫层用途部位，不再由 AI 随机决定是否澄清。
2. AI 不得新增或删除本地澄清字段，也不得把本地 `ready_for_review` 方案随机降级。
3. 用户回答“基础垫层”或“楼地面垫层”后，回答会并回原施工事项并重新检索。
4. 首屏结论直接显示“建议清单 + 主定额”的编号和名称，不再以通用模板句作为核心结论。
5. 待确认区域改为中性表面，状态通过文字表达，减少大面积警示色造成的视觉噪声。
6. Windows 文件版本、产品版本和应用版本统一为 0.7.3。

## 距离成熟产品的真实差距

### 1. 缺少专家黄金集

当前没有 300 条以上、覆盖建筑/安装/市政/园林的真实工程描述及专家标注，因此不能宣称“套项准确率达到某个百分比”。这是当前最大的发布阻塞，不应使用合成用例替代。

黄金集至少应标注：

- 施工事项边界和专业；
- 必问字段及允许“不确定”的处理；
- 清单编码、主定额、增补/调整/运输项；
- 单位换算、系数、排除项和证据页；
- 无可靠匹配时的正确拒判结果。

### 2. 复杂专业规则覆盖不足

垫层、防水、土方、配管等高频场景已有基础规则，但章节说明、换算条件、材料替换、超高、泵送、脚手架、模板和运输组合仍需按专业逐项建模。

### 3. 原书证据仍有缺口

当前资料库包含来源路径和页码，但 2013 清单及部分 2024 标准记录仍存在未登记页。正式使用前应让高频候选达到可打开原书页的完整证据覆盖。

### 4. 尚缺规模化真实用户验证

需要至少 5 名造价人员完成 50 个真实任务，记录澄清是否必要、候选是否正确、完成耗时、人工改动和失败原因。仅凭开发机冒烟测试不能证明同事环境中的长期稳定性。

### 5. 安装包信任链未完成

内部安装包可用，但未签名时 Windows 可能显示未知发布者。公开分发前需要代码签名证书、隐私和资料授权复核，以及可重复的正式发布流程。

## 进入 1.0 的量化门槛

- 至少 300 条专家黄金案例，四个专业均有覆盖；
- 必问字段召回率不低于 95%，不必要澄清率低于 10%；
- 清单 Top-3 召回率、主定额 Top-3 召回率和完整组合通过率分别统计，不用一个模糊“准确率”代替；
- 同一输入、同一资料版本重复运行 20 次，确定性状态一致率 100%；
- 关键候选原书证据可定位率不低于 95%；
- 5 名真实用户、50 个任务中无数据损坏和阻断性崩溃；
- 安装、升级、卸载、DPI、深浅主题和离线模式完成独立 Windows 环境验证。

## 下一阶段优先级

1. 建立脱敏的专家黄金集和错误分类，不再凭主观印象优化准确率。
2. 按高频场景补确定性必问规则与组合完整性校验。
3. 修补高频记录的原书页码和跨机器来源路径映射。
4. 用真实任务数据继续压缩结果页，仅保留结论、方案、待确认和证据四层。
5. 完成签名、升级兼容和正式发布门禁后再定义 1.0。
