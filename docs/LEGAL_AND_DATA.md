# 资料权利与使用边界

## 开源范围

MIT 许可证覆盖本仓库中的原创应用代码、测试代码和原创界面资源。第三方字体继续适用其独立许可证。

## 不随仓库发布的内容

- 山东定额、清单、人材机价格和配套 PDF。
- 由上述资料生成的 SQLite 数据库、全文索引和数据摘要。
- 第三方计价软件、插件、可执行文件、图标、截图和数据文件。
- 历史安装包、便携包、构建缓存和内部审计材料。
- API Key、凭据密文、会话、日志和用户工程描述。

## 使用者责任

使用者在接入本地资料库前，需要确认自己对数据的复制、加工、检索、内部分发和向第三方 AI 提交摘要分别具有所需权利。内部使用权不当然等于公开发布权。

## AI 服务

应用只提供可选接口适配。AI 服务的费用、可用性、数据处理、内容保留和区域合规性由用户与相应服务商之间的账号和协议决定。本项目不提供、转售或共享任何 AI 账号与密钥。

## 专业结果

本工具输出的是检索候选、条件提示和辅助解释。最终套项、换算、计价和合同结算应由具备相应能力的人员根据有效资料、项目特征和合同约定复核。
