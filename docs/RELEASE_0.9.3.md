# 0.9.3 发布说明

## 下载体积

- 发行库只保留福莱结构化定额、清单、关联、人材机和规则数据。
- PDF、OCR 页、原书路径、原始导入 JSON 和开发全文索引不进入下载包。
- 真实结构化运行库由 2.71 GB 降至约 218 MB。

## 兼容性

- 从结构化字段重建定额、清单和规则检索记录，保留四专业与双版本隔离。
- 人材机改用轻量文本摘要，候选详情和 AI 上下文仍可读取。
- “暗配/明配”等明确施工方式不再依赖 PDF 页码作为排序依据。
- 无原书页时继续按结构化资料核验，原书状态单独标记为可选复核。

## 验证

- 精简库与开发原库均通过 300 项自动化测试。
- 精简库保留 61,807 条定额、53,441 条清单、94,923 条关联和 748,156 条人材机消耗。
