# 0.8.0 发布说明

## 界面与交互

- 使用中性灰、低饱和深绿色和统一设计 token 重构浅色与深色主题。
- 缩窄侧栏并压缩历史记录，AI 套价分析保持为主入口。
- 输入区隐藏空计数，补充条件与示例降级为次要操作。
- 结果区先显示结论和事项方案，待补条件使用紧凑语义区域，核对依据默认折叠。
- 修复 SVG 回退图标、Windows 原生标题栏颜色和 150% DPI 内容截断。
- 自动滚动改为 220ms 可取消缓动，鼠标滚轮输入会立即接管。

## 安装

- 完整版 Release 改为单个 `ShandongQuotaAssistant-Setup-0.8.0.exe`，不再需要手动下载和配对 `.bin`。
- 安装后自动创建桌面与开始菜单入口。
- 保留完整便携 `.7z` 作为备用交付方式。

## 验证

- 浅色、深色和 980×680 紧凑窗口均完成实机截图验收。
- DeepSeek 实际对话返回结构化结果，本地白名单与原书证据校验通过。
- 全量单元测试、Ruff、compileall、SQLite quick_check 和发布 manifest 门禁作为构建前置条件。
