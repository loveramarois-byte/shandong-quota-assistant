# 0.8.5 发布说明

## 这次改了什么

- AI 设置收敛为“连接并获取模型”一个动作：自动读取模型、选择可用模型并完成真实对话探针。
- ccSwitch 未返回模型清单时自动尝试兼容模型，不再要求新手理解两套连接步骤。
- 推荐结果默认只保留“复制方案”和“查看依据”两个动作，导出与候选细节继续按需展开。
- 启动预热改为真实检索链路预热，覆盖分词、FTS、结构化检索、排序与清单定额关联。
- 100 次实机演练增加易用性、成熟度、新手使用、API 连通性、UI 直观性和简洁度六维评分。

## 验收

- Windows 完整结构化资料库 100 次实机演练：100/100 通过。
- 本地分析延迟：P50 约 1.04 秒，P95 约 2.55 秒，最大约 3.23 秒。
- DeepSeek 模型读取和真实对话成功；ccSwitch 兼容模型真实对话成功；智谱未配置时准确显示“未配置”。
- 详细结果见 `evaluation/reports/real-machine-100-v0.8.5.json` 与 `evaluation/REAL_MACHINE_100_RUNS_V0.8.5.md`。
