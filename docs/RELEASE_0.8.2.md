# 0.8.2 发布说明

## 结构化资料优先

- 福莱式结构化清单、定额、关联和人材机数据成为普通套项的主要依据。
- 本地清单—定额关联合法时，即使没有 PDF 页，也可以确认、复制并导出方案。
- 原书页调整为可选复核入口；换算、非 1.0 系数、争议或未挂页主定额会显示重点复核提醒。
- AI 只负责解释和选择本轮白名单，不能覆盖本地资料状态或把结构化记录降级为模型推断。

## 结果与业务修复

- 结果区统一显示“本地结构化资料已校验”，不再把“原书证据待定位”当作普通方案的错误状态。
- CSV 的“证据”列改为“资料依据”，无 PDF 页时明确写入“结构化定额库已匹配”。
- 修复“基础 C15 混凝土垫层”可能误选混凝土钢筋清单的问题，施工对象优先于泛材料词命中。
- 演示资料库补齐结构化来源状态字段，与正式 schema 的查询路径保持一致。

## 安装说明

完整安装包仍为单文件，安装后即可使用内置资料库。当前公开安装包未进行 Windows 代码签名，首次运行时可能显示未知发布者提示，请从项目 Release 下载并核对 SHA-256。
