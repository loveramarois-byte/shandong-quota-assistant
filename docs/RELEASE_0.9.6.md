# 0.9.6 发布说明

## 正式清单输出

- 本地匹配结果首屏增加清单完成度摘要：清单描述、项目特征、计算规则和定额数量一眼可见。
- 结果明确区分“可直接复核”和“待补条件”，减少把候选结果误当成最终清单的风险。
- 保留正式清单表格、项目特征、工程量计算规则、工作内容和整行复制能力。
