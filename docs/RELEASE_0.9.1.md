# 0.9.1 发布说明

## 修复

- AI 复核完成后，缺少施工方式等关键条件时，最终结论面继续显示可点击选项。
- 条件补齐并重新匹配后，通过本地结构校验的方案显示“人工确认”按钮。
- 人工确认状态写回当前会话，重新打开历史分析后仍可恢复。

- 新手文案改为“简单说，这项定额已经包括……”，不再直接展示难读的原始字段。
