# 0.9.2 发布说明

## 新增

- 清单与定额候选行新增“复制整行”，按编码、名称、单位、版本、专业、页码六列复制。
- Windows 剪贴板同时提供 Excel 可识别的文本格式，保留长编码和前导零。
- 复制成功后显示“已复制”，1.5 秒后自动恢复。

## 优化

- 浅色主题辅助文字达到 WCAG AA 正文对比度要求。
- 主界面与兼容界面共用候选行格式，避免复制结果不一致。
- 固化旧界面 Header 的单一 grid 布局，防止窗口缩放时按钮遮挡标题。

## 验证

- Ruff、compileall 与 298 项自动化测试通过。
- 1080×680、1280×820 离屏实测中，复制按钮完整显示且未越出结果卡片。
