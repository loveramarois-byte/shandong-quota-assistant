# 0.9.5 发布说明

## 产品打磨

- AI 连接失败统一转换为可执行提示，不再把裸 HTTP 状态码直接丢给用户。
- ccSwitch 返回 503 时明确说明：本机服务已启动，但没有可用上游模型，并给出恢复动作。
- API Key 401/403、连接超时和网关 502 使用统一的设置页与分析页文案。

## 验证结果

- 单元测试：320/320 通过。
- Windows 本地 100 项实机回归：100/100 通过。
- Qt 主流程 50 轮：50/50 通过。
- 真实 ccSwitch 探针已执行；当前机器返回空模型列表和 HTTP 503，软件能保留本地清单定额能力并给出恢复提示。

## 资料边界

运行包仍只携带约 218 MB 的结构化 SQLite 资料库，不包含 PDF、OCR 页、原始导入数据或开发机路径。
