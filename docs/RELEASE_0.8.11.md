# 0.8.11 发布说明

- AI 复核卡片重构为“结论、推荐依据、下一步、套价摘要、专业明细”的渐进式信息结构。
- 首屏使用普通用户可理解的部位、材料、厚度和施工方式描述，清单编码、定额编号及来源编号默认收起。
- 施工方式选项增加可观察动作说明，例如“使用喷灯加热粘贴 · 热熔法”。
- 用户确认条件后替换上一轮结果与 AI 卡片，避免重复方案同时显示。
- 普通鼠标滚轮加入轻量平滑滚动；用户开始滚动或展开明细后立即暂停自动跟随，避免 AI 内容增长抢走阅读位置。
- 修复长用户描述气泡宽度过窄导致文字显示不完整的问题。

GitHub 与 Gitee 发行版提供安装程序和 SHA-256 校验文件。
