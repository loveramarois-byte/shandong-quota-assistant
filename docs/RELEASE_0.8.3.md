# 0.8.3 发布说明

## 紧凑资料库

- 保留全部清单、定额、关联、人材机和检索用 `chunks` 记录。
- 去除重复的 PDF/OCR FTS5 影子表，增加清单、定额、专业和标题范围索引。
- 没有 FTS5 的运行包自动使用本地范围约束 + LIKE 回退，普通套项结果与原库保持一致。
- 公开安装包不再携带 PDF 原书，安装后直接使用内置结构化资料，不要求先核实原书。

## 交付

- 安装后可直接检索山东 2016/2025 定额、2013/2024 清单及人材机。
- `release-manifest.json` 同时记录原始数据库哈希、紧凑运行库哈希和是否包含 PDF 证据文件。
