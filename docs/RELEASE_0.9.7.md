# 0.9.7 发布说明

## 清单成果工作台

- 结果页从普通候选卡升级为正式工程量清单成果预览。
- 清单采用固定的序号、项目编码、项目名称、计量单位表头。
- 项目特征描述、工程量计算规则和工作内容作为正式字段行展示。
- 缺失字段使用克制的待补状态，避免把不完整方案误当成最终成果。
- 资料依据与定额行形成独立层级，审阅时无需在长文本里寻找来源。

## 验证结果

- 单元测试：322/322 通过。
- Windows 本地 100 项实机回归：100/100 通过，0 失败。
- Qt 主流程 50 轮：50/50 通过，0 失败；浅色/深色主题、滚动和会话刷新均覆盖。
- SQLite：`quick_check=ok`，`user_version=3`，结构化 chunks 130404 条。

## 资料边界

运行包只携带约 218 MB 的结构化 SQLite 资料库，不包含 PDF、OCR 页、原始导入数据或开发机路径。
