# 0.8.1 发布说明

## 安装体验

- 仍然只需下载一个完整安装包，不依赖 Python、数据库压缩分卷或其他运行库。
- 首次打开后只保留一个“一键安装”确认页，不再询问安装目录和开始菜单位置。
- 默认安装到当前用户目录，不触发管理员权限请求。
- 自动创建桌面和开始菜单入口，完成后自动启动软件，不再要求点击“完成”。
- 覆盖安装时沿用原目录并保留当前用户的 AI 设置、历史记录和主题偏好。
- 支持 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`，方便单位内部批量部署。

## 已知提示

当前公开安装包未进行 Windows 代码签名，首次下载或运行时 Windows 可能显示未知发布者提示。请从项目 Release 下载并核对 SHA-256；配置正式代码签名证书后可进一步减少此提示。
