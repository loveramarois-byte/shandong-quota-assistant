# 0.9.7 下载说明

GitHub Release 为避免单个资产超过当前网络链路限制，安装包和便携包各提供两个分卷。

## 安装包

- `ShandongQuotaAssistant-Setup-0.9.7.exe.001`
- `ShandongQuotaAssistant-Setup-0.9.7.exe.002`

```powershell
cmd /c copy /b ShandongQuotaAssistant-Setup-0.9.7.exe.001+ShandongQuotaAssistant-Setup-0.9.7.exe.002 ShandongQuotaAssistant-Setup-0.9.7.exe
```

## 便携版

```powershell
cmd /c copy /b ShandongQuotaAssistant-Portable-0.9.7.7z.001+ShandongQuotaAssistant-Portable-0.9.7.7z.002 ShandongQuotaAssistant-Portable-0.9.7.7z
```

使用 `SHA256SUMS.txt` 校验合并后的完整文件。
